2. DUAL-PIPELINE DESIGN (ASTM vs Roadessy)
================================================================================

PIPELINE 1: ASTM (International Standard)
-----------------------------------------
IRI Method: Quarter-Car Model (QCM) simulation per ASTM E1926/E950
  - Target sampling frequency: 100 Hz (upsampled via resample_poly)
  - Reference speed: 80 km/h (22.22 m/s)
  - Spatial resolution: 25mm (0.025m)
  - Distance computed from: speed × time (standardized simulation)
  - NOT from GPS Haversine (by design - QCM simulates at reference speed)

Vision Method: MDPI Sensors 2024 paper (Ibragimov et al.)
  - YOLO distress detection
  - AASHTO R85-18 + ASTM D6433-18 classification
  - Polynomial DV (Deduct Value) curves

PCI Output: ASTM PCI = 100 - CDV (Corrected Deduct Value)
IRI reported SEPARATELY per ASTM D6433

PIPELINE 2: Roadessy (Custom/Ghana-aligned)
-------------------------------------------
IRI Method: Simple displacement-to-distance method (Enochs Thesis Eq 2.9/3.9)
  - Travel distance from Haversine lat/lon
  - IRI = sum(|Δvertical_displacement|) / distance_km (m/km)
  - Distance computed from GPS Haversine coordinates

Vision Method: Ghana Manual 2023 Table 3 ratings
  - YOLO distress detection
  - Ghana-specific distress type mapping
  - Custom DV computation with weights

PCI Output: Roadessy PCI = 100 - corrected(DV_sum)
  - Correction factor: 1.2 (prototype, verify against RMM manual)
  - DV_sum = Σ(avg_rating × weight) per distress type
  - IRI reported separately

5. INERTIAL SERVICE (app/services/inertial_service.py)
================================================================================

CLASS: InertialRefineryService

METHOD 1: process_vibration_data() - Simple Displacement IRI
-----------------------------------------------------------
Input: timestamps (s), accel_z (m/s²), speeds_kmh, latitudes, longitudes
Output: InertialPipelineResult

Steps:
  1. Build DataFrame with sensor data
  2. Run preprocessing pipeline (ST1-ST5b) via PreprocessingPipeline.run_pipeline()
  3. Extract vertical_displacement from processed data
  4. Compute travel distance via Haversine formula from lat/lon

Haversine Formula:
  φ1, φ2 = lat1, lat2 in radians
  Δφ = radians(lat2 - lat1)
  Δλ = radians(lon2 - lon1)
  a = sin²(Δφ/2) + cos(φ1)·cos(φ2)·sin²(Δλ/2)
  c = 2·atan2(√a, √(1-a))
  distance = R · c  (R = 6371000.0 m, Earth radius)

Cumulative distance = cumsum of haversine distances between consecutive points

Segment Processing (50m segments):
  accumulated_dist = 0.0
  accumulated_disp = 0.0
  prev_vert_disp = 0.0
  
  For each point i:
    dist_delta = distances[i] - distances[i-1]
    accumulated_dist += dist_delta
    vert_change = |vert_disp[i] - prev_vert_disp|
    accumulated_disp += vert_change
    prev_vert_disp = vert_disp[i]
    
    if accumulated_dist >= segment_length_m (50.0):
      seg_iri = accumulated_disp / (accumulated_dist / 1000.0)  # m/km
      record IRISegment(start_m, end_m, iri_m_km=seg_iri)
      reset accumulators

Segment IRI Formula (Enochs Thesis Eq 2.9/3.9):
  IRI = Σ|Δvertical_displacement| / distance_km   (units: m/km)

Overall IRI = mean of all segment IRIs

METHOD 2: process_astm_qcm() - ASTM Quarter-Car Model
-----------------------------------------------------
Input: timestamps, accel_z, speeds_kmh, target_fs=100.0, target_dx=0.025, v_ref_kmh=80.0
Output: ASTMQCMResult

Steps:
  1. Sort data by timestamp
  2. Compute original sampling frequency: fs = 1/median(dt)
  3. Quality flags:
     - low_sampling_rate: if original_fs < 100 Hz
     - speed_variation: if speed CV > 0.2
     - insufficient_distance: if total_distance < 100m
     - profile_gaps: if gap_ratio > 5%
     - quarter_car_divergence: if max displacement > 1m

  4. Upsample to 100 Hz using resample_poly (polyphase) or linear interpolation

  5. High-pass filter at 0.1 Hz (Butterworth order 2):
     b, a = butter(N=2, Wn=0.1, btype="highpass", fs=100.0)
     velocity_z = filtfilt(b, a, cumsum(accel * dt))
     disp_z = filtfilt(b, a, cumsum(velocity_z * dt))

  6. Resample to uniform spatial spacing (0.025m):
     d_uniform = arange(0, total_distance, 0.025)
     profile_uniform = interp(d_uniform, distances, disp_z)

  7. Quarter-Car Model Simulation (RK4 integration):

  State vector: x = [sprung_disp, sprung_vel, unsprung_disp, unsprung_vel]
  
  Derivatives:
    dx1/dt = x2  (sprung velocity)
    dx2/dt = (-ks·(x1-x3) - cs·(x2-x4)) / ms  (sprung acceleration)
    dx3/dt = x4  (unsprung velocity)
    dx4/dt = (ks·(x1-x3) + cs·(x2-x4) - kt·(x3-zr)) / mu  (unsprung acceleration)

  RK4 Integration:
    k1 = f(x, zr)
    k2 = f(x + 0.5·dt·k1, zr)
    k3 = f(x + 0.5·dt·k2, zr)
    k4 = f(x + dt·k3, zr)
    x_next = x + (dt/6)·(k1 + 2·k2 + 2·k3 + k4)

  IRI accumulation:
    IRI_accum += |x[1] - x[3]| · dt  (absolute relative velocity between sprung and unsprung)

  Final IRI calculation:
    IRI = IRI_accum / total_distance · 1000  (mm/m, which equals m/km)

  Time integration:
    dt = target_dx / v_ref_ms = 0.025 / 22.22 = 0.001125 s

  50m segment computation:
    points_per_segment = 50.0 / 0.025 = 2000
    seg_iri = segment_iri_accum / segment_distance · 1000

METHOD: classify_iri_5rank(iri)
  IRI < 2.0  -> "Very Good" (code 1)
  IRI < 4.0  -> "Good" (code 2)
  IRI < 6.0  -> "Fair" (code 3)
  IRI < 8.0  -> "Poor" (code 4)
  IRI >= 8.0 -> "Very Poor" (code 5)

6. PREPROCESSING PIPELINE (app/services/preprocessing_pipeline.py)
================================================================================

CLASS: PreprocessingPipeline

Implements ST1-ST5b preprocessing stages per reference codebase:

ST1: Format Data
  - Rename columns from phone sensor format to standard names
  - Mapping: 'ACCELEROMETER X (m/s²)' -> 'accel_x', 'GRAVITY X (m/s²)' -> 'gravi_x', etc.
  - Convert numeric columns using pd.to_numeric(errors='coerce')

ST2: Speed Filter
  - Compute acceleration magnitude: |a| = √(ax² + ay² + az²)
  - Remove rows where |a| < 0.1 (stationary threshold = 0.1g)
  - Remove GPS speed < 5 km/h (SPEED_THRESHOLD_KMH)
  - Remove GPS speed > 100 km/h (MAX_SPEED_KMH)

ST3: Reorientation (Gravity Vector Alignment)
  - Input: accelerometer (ax, ay, az) + gravity vector (gx, gy, gz)
  - Normalize gravity: ĝ = g / |g|
  - Project acceleration onto gravity-aligned frame
  - a_dot_g = ax·gx + ay·gy + az·gz
  - Reoriented Z (vertical): az' = a · ĝ
  - Reoriented X: ax' = ax - (a·ĝ)·ĝx
  - Reoriented Y: ay' = ay - (a·ĝ)·ĝy

ST4: Z-axis Filter
  - No filtering (passthrough)
  - Actual IRI filtering happens in ST5b

ST5: Location Filter
  - Remove GPS duplicates (drop_duplicates on lat/lon)
  - Only if meaningful GPS variation (std > 1e-6)

ST5b: Vertical Displacement (Correct IRI Filter Sequence)
  1. Remove mean from acceleration: a_corrected = a - mean(a)
  2. Integrate to velocity (trapezoidal):
     v[i] = v[i-1] + 0.5·(a[i] + a[i-1])·dt[i]
  3. High-pass filter velocity at 0.1 Hz (Butterworth order 2):
     b, a = butter(N=2, Wn=0.1, btype='high', fs=actual_fs)
     v = filtfilt(b, a, v)
  4. Integrate velocity to displacement (trapezoidal):
     d[i] = d[i-1] + 0.5·(v[i] + v[i-1])·dt[i]
  5. High-pass filter displacement at 0.1 Hz:
     d = filtfilt(b, a, d)
  6. Remove linear trend: d = d - polyfit(d, degree=1)
  7. Clip: d = clip(d, -5.0, 5.0) meters

Sampling frequency calculation:
  dt = diff(time_ms / 1000.0)
  dt = insert(dt, 0, dt[0])
  dt = clip(dt, 0.001, 1.0)
  fs = 1.0 / median(dt)
  fs = clip(fs, 10.0, 200.0)

CLASS: VisionAnalysisService

Camera Parameters:

  - camera_tilt_deg (default 0°)
  - fx, fy (default 1000.0) - focal lengths in pixels
  - cx, cy (default 960.0, 540.0) - principal point
  - distortion_coefficients (optional)

Camera Matrix K:
  K = [[fx, 0, cx],
       [0,  fy, cy],
       [0,  0,  1]]

METHOD: undistort_frame(frame)
  - Uses cv2.getOptimalNewCameraMatrix and cv2.undistort
  - Applies distortion coefficients (5 params, zero if none)

METHOD: _pixel_to_real_world(bbox, img_shape) - Pinhole Model
  Input: bbox = [x1, y1, x2, y2] in pixels
  
  w_px = |x2 - x1|
  h_px = |y2 - y1|
  y_center = (y1 + y2) / 2
  
  Pinhole Depth Estimation:
    angle_y = atan2((y_center - cy), fy)
    total_angle = tilt_rad + angle_y
    z_m = camera_height_m / sin(total_angle)  (distance from camera)
  
  Real-world dimensions:
    width_m = (w_px · z_m) / fx
    length_m = (h_px · z_m) / fy
    area_m2 = width_m · length_m

METHOD: _calculate_deduct_value(class_id, area_m2)
  density = min(area_m2 / 100.0, 1.0) × 100
  base_dv = 15.0 · ln(1 + density)
  return clip(base_dv, 0, 100)

Severity Classification:
  - Pothole:
    diameter_mm >= 750 OR depth_mm > 50    -> "HIGH" (ghana_rating=7)
    depth_mm > 25 OR diameter_mm >= 300    -> "MEDIUM" (ghana_rating=4)
    else                                  -> "LOW" (ghana_rating=2)
  - Crack (class 2):
    width_mm > 10 -> HIGH (7), width_mm > 3 -> MEDIUM (4), else LOW (2)
  - Rutting/Shoving (6,7):
    area_m2 > 0.5 -> HIGH (7), area_m2 > 0.1 -> MEDIUM (4), else LOW (2)
  - Others:
    area_m2 > 1.0 -> HIGH (7), area_m2 > 0.2 -> MEDIUM (4), else LOW (2)

METHOD: process_video_astm(video_path, gps_points, target_fps=15.0)
  1. Open video with cv2.VideoCapture
  2. Get: original_fps, width, height, total_frames
  3. FPS flag per MDPI paper:
     - fps >= 15 -> "OK"
     - fps >= 10 -> "LOW_FPS"
     - else      -> "INSUFFICIENT"
  4. Create GPS interpolator (linear interpolation of lat/lon by timestamp)
  5. Frame interval = max(1, int(original_fps / target_fps))
  6. For each sampled frame:
     a. Undistort frame
     b. Get GPS position via interpolator
     c. Run YOLO detection: results = model(frame, verbose=False)
     d. For each detection box:
        - Extract class_id, confidence, xyxy bbox
        - Compute real-world dimensions via pinhole model
        - Compute ASTM name, Ghana name, defect name
        - Compute deduct value: dv = 15·ln(1 + density)
        - Chainage = timestamp × 10.0 (assumes 10 m/s = 36 km/h)
        - Store detection in list

8.2 GEOMETRY-ANCHORED DEPTH SCALER (app/services/geom_anchor.py)
-----------------------------------------------------------------
CLASS: GeometryAnchoredDepthScaler

Purpose: Convert relative inverse depth to METRIC depth using ground plane geometry

Constructor params:
  - camera_height_m (default 1.5)
  - pitch_deg (default 0)
  - roll_deg (default 0)
  - fx, fy, cx, cy (camera intrinsics)

METHOD: compute_ground_plane(pitch, roll, height) -> (n, d)
  - Computes ground plane normal n and distance d in camera coordinates
  - Rotation matrices:
    Rx (pitch): [[1, 0, 0], [0, cos(-pitch), -sin(-pitch)], [0, sin(-pitch), cos(-pitch)]]
    Rz (roll):  [[cos(roll), -sin(roll), 0], [sin(roll), cos(roll), 0], [0, 0, 1]]
  
  - World to camera rotation: R_w2c = Rz @ Rx
  - Ground normal: n_world = [0, 0, 1] (pointing up)
  - n_cam = R_w2c @ n_world
  - Point on ground: p_ground_world = [0, -height, 0]
  - p_ground_cam = R_w2c @ p_ground_world
  - Plane distance: d = -n_cam · p_ground_cam

METHOD: estimate_scale_from_ground_plane(inv_depth, K, ...) -> (scale, shift)
  1. Compute ground plane normal n and distance d
  2. Create camera ray directions from pixel coordinates:
     x_cam = (u - cx) / fx
     y_cam = (v - cy) / fy
     rays = [x_cam, y_cam, 1] (normalized)
  3. Intersect rays with ground plane:
     n_dot_ray = sum(rays · n_ground)
     t = -d / n_dot_ray  (metric depth from ground plane intersection)
  4. Linear regression to find scale/shift:
     metric_depth = scale × (1/inv_depth) + shift
     A = [[1/inv_d[0], 1], [1/inv_d[1], 1], ...]
     [scale, shift] = lstsq(A, metric_depth)

METHOD: apply(inv_depth, K, pitch, roll, height) -> metric_depth
  1. If not initialized: estimate scale/shift from ground plane
  2. Apply EMA smoothing to scale/shift:
     scale = prev_scale × (1 - alpha) + new_scale × alpha
     shift = prev_shift × (1 - alpha) + new_shift × alpha
  3. metric_depth = scale / (inv_depth + 1e-6) + shift
  4. Clip to [0, 100] meters

8.3 MBTP AREA ESTIMATOR (app/services/mbtp_est.py)
---------------------------------------------------
CLASS: MBTPAreaEstimator

"Minimum Bounding Triangulated Pixel" method

Purpose: Estimate pothole area, depth, and volume using triangulation

Constructor params:
  - depth_threshold_m = 0.02  (2cm depth threshold for segmentation)
  - min_area_pixels = 100
  - contour_simplification_eps = 0.005

METHOD: segment_pothole_region(depth_map, bbox, ground_ref) -> mask
  1. Extract ROI from depth_map using bbox
  2. Determine depth orientation (check if bottom half is deeper than top half)
  3. Segmentation:
     If inverted depth: mask = (roi - ground_ref) > threshold
     Else: mask = (ground_ref - roi) > threshold
  4. Morphological operations:
     - Close: cv2.morphologyEx(MORPH_CLOSE, ellipse(5,5))
     - Open: cv2.morphologyEx(MORPH_OPEN, ellipse(5,5))
  5. Remove small regions (connectedComponentsWithStats, area < min_area_pixels)

METHOD: compute_contour(mask) -> [contour]
  - Extract contours with cv2.findContours
  - Select largest contour
  - Douglas-Peucker simplification: eps = contour_eps × arcLength

METHOD: triangulate_contour(contour, image_shape) -> (triangles, viz)
  1. Extract points from contour
  2. Add centroid for full coverage
  3. Delaunay triangulation via cv2.Subdiv2D
  4. Filter triangles whose centroid is outside contour

METHOD: compute_triangle_area(triangle, depth_map, fx, fy, ground_ref) -> area_m2
  1. Get depths at triangle vertices from depth_map
  2. Convert to 3D points via pinhole:
     X = (u - cx) · Z / fx
     Y = (v - cy) · Z / fy
     Z = depth at pixel
  3. Triangle area via cross product:
     area = 0.5 × |cross(p2-p1, p3-p1)|

METHOD: estimate(rgb_image, depth_map, bbox, K, ground_ref) -> MBTPEstimate
  1. Compute ground reference (median depth in 10px border ring around bbox, excluding bbox interior)
  2. Use RobustPotholeSegmentor to segment pothole
  3. Extract contour
  4. Triangulate contour -> compute total area (sum of triangle areas)
  5. Convex hull area for irregularity metric:
     irregularity = 1 - (total_area / convex_hull_area)
  6. Volume integration:
     depth_deficit = max(ground_ref - roi_depth, 0)
     pixel_area_m2 = (ground_ref/fx) × (ground_ref/fy)
     volume = Σ(depth_deficit[mask>0]) × pixel_area_m2
  7. Confidence:
     method_confidence = {"depth": 0.9, "rgb_water": 0.7, "hybrid": 0.8, fallback: 0.5}
     confidence = method_conf × min(1, total_area / (hull_area + 0.001))

MBTPEstimate dataclass fields:

9. SFM-BASED DEPTH SERVICE (app/services/depth_service.py)
================================================================================

CLASS: DepthEstimationService

Purpose: Structure-from-Motion (SfM) based depth estimation with RANSAC plane fitting
         and temporal EMA smoothing

Constants:
  MIN_OBSERVATIONS = 2
  MIN_MATCHES = 30
  MIN_INLIERS = 20
  MIN_PLANE_POINTS = 15
  MIN_DEFECT_POINTS = 5
  _alpha = 0.35  (EMA smoothing factor)

METHOD: estimate_track_depth(observations, camera_matrix, camera_height_meters, track_id)
  -> DepthEstimationResult

Steps:
  1. Check len(observations) >= MIN_OBSERVATIONS (else "insufficient observations")
  2. Select first and last observation pair for baseline
  3. Blur rejection via Variance of Laplacian:
     blur_score = cv2.Laplacian(gray, CV_64F).var()
     If blur_score < 80.0: reject frame ("motion blur")
  4. Feature matching (ORB + BFMatcher with ratio 0.75):
     - orb = cv2.ORB_create(3000)
     - Detect keypoints and descriptors
     - Match with knnMatch(k=2)
     - Apply Lowe's ratio: m.distance < 0.75 × n.distance
  5. Essential matrix estimation:
     essential = cv2.findEssentialMat(pts1, pts2, K, method=RANSAC, prob=0.999, threshold=1.0)
  6. Pose recovery:
     _, R, t, pose_mask = cv2.recoverPose(essential, pts1, pts2, K, mask=inlier_mask)
  7. Triangulation:
     P1 = K @ [I | 0]  (identity)
     P2 = K @ [R | t]  (second pose)
     homog = cv2.triangulatePoints(P1, P2, pts1.T, pts2.T)
     pts3d = homog[:3] / homog[3]  (normalize homogeneous)
  8. Filter by z > 0 and isfinite
  9. Split points into road vs defect using polygon/bbox masking
  10. RANSAC Plane Fitting on road points:
      - 80 iterations
      - Sample 3 random points
      - Compute normal: n = cross(p2-p1, p3-p1), normalize
      - Compute d = -n · p1
      - Inliers: |n · pt + d| < 0.05 (5cm tolerance)
      - Select best (most inliers)
  11. Scale computation:
      camera_to_plane = |plane_d| / |plane_n|
      scale = camera_height_meters / camera_to_plane
  12. Depth computation:
      dist = (defect_pts @ plane_n + plane_d) / |plane_n|
      depth_mm = |dist| × scale × 1000
      depth_mm = depth_mm[isfinite(depth_mm)]
  13. 95th percentile for max_depth, mean for mean_depth
  14. Temporal EMA smoothing (if track_id provided):
      max_depth = ema(prev_max_depth, max_depth, alpha=0.35)
      ema(prev, new) = prev × (1-alpha) + new × alpha
  15. Confidence:
      confidence = min(matches/120, 1) × 0.3
                 + min(inliers/80, 1) × 0.3
                 + min(defect_pts/12, 1) × 0.2
                 + min(road_pts/40, 1) × 0.2

DepthEstimationResult fields:
  - max_depth_mm, mean_depth_mm, confidence, method="sfm_ransac_plane_ema"
  - matched_points, inlier_points, defect_points, road_plane_points

METHOD: get_severity_from_width(distress_type, width_mm) -> SeverityLevel
  - Longitudinal/Transverse cracks:
    width < 5mm -> Low, < 20mm -> Medium, else High
  - Alligator/Potholes/Depression:
    width < 300mm -> Low, < 750mm -> Medium, else High
  - Ravelling/Rutting/Shoving:
    width < 100mm -> Low, < 500mm -> Medium, else High
  - Patching:
    width < 200mm -> Low, < 500mm -> Medium, else High
  - Bleeding/Corrugation:
    width < 100mm -> Low, else Medium

METHOD: compute_density(distress, section_area_m2) -> float
  Density = (distress_amount / section_area) × 100  (ASTM D6433 Eq 8)

  Where distress_amount depends on type:
    - Linear (cracks): amount = length_m
    - Area (alligator, patching, ravelling, rutting, shoving, bleeding, corrugation): amount = area_m2
    - Count-based (potholes, depression): amount = count × typical_area
      Potholes: length_m × 0.1
      Depression: length_m × 0.5

METHOD: get_dv(distress_type, severity, density) -> float
  a, b, c = DV_COEFFICIENTS[distress_type][severity]
  DV = a × density² + b × density + c
  return max(0, DV)

METHOD: get_cdv(distress_type, tdv) -> float
  a, b, c = CDV_COEFFICIENTS[distress_type]
  CDV = a × TDV² + b × TDV + c
  return max(0, CDV)

METHOD: compute_section_pci(section) -> Dict
  1. Group distresses by type
  2. For each type:
     - Sum DVs: TDV = Σ DV_i (per distress instance)
     - Compute CDV: cdv = get_cdv(distress_type, TDV)
     - Add to total_cdv
  3. Apply multi-distress correction:
     corrected_cdv = total_cdv × CORRECTION_FACTORS[min(n_types, 5)]
  4. PCI = max(0, min(100, 100 - corrected_cdv))

PCI Rating Classes (ASTM D6433-18 Table 2):
  86-100:  Good
  71-85:   Satisfactory
  56-70:   Fair
  41-55:   Poor
  26-40:   Very Poor
  11-25:   Serious
  0-10:    Failed

METHOD: compute_pci_from_detections(detections, total_length_m, ...) -> Dict
  1. Create 50m sections
  2. For each section, filter detections by chainage
  3. Convert YOLO detections to Distress objects:
     - Linear distress: length_m = area_m2 / width_m
     - Count-based: length_m = 1.0 (each detection = 1 count)
     - Area-based: length_m = 0
     - width_mm = width_m × 1000
  4. Compute PCI per section via compute_section_pci
  5. Overall PCI = mean of section PCIs

12. SPATIAL & MAP MATCHING SERVICE (app/services/spatial_service.py)
================================================================================

CLASS: SpatialService

Coordinate Systems:
  - WGS84 (EPSG:4326) for input/output
  - UTM projection for metric calculations

METHOD: wgs84_to_utm(lon, lat) -> (easting, northing, zone, hemisphere)
  zone = min(60, max(1, int((lon + 180) / 6) + 1))
  hemisphere = "north" if lat >= 0 else "south"
  epsg = (32600 if lat >= 0 else 32700) + zone
  Uses pyproj.Transformer from EPSG:4326 to EPSG:{epsg}

METHOD: compute_linear_chainage(coords_df) -> chainage_m
  Haversine cumulative distance:
  a = sin²(Δφ/2) + cos(φ1)·cos(φ2)·sin²(Δλ/2)
  distance = 2 × 6371000 × arcsin(√a)
  chainage = cumsum(distances)

METHOD: map_match_trajectory(gps_df, centerline_wkt, road_id, db, max_distance_m=100)
  1. Extract valid GPS points (lat/lon in valid ranges)
  2. Build trajectory LineString
  3. If db provided and road_id: fetch centerline from gh_roads table
  4. Transform to metric coordinates (UTM)
  5. For each GPS point:
     - Find nearest point on centerline (Shapely nearest_points)
     - Compute distance from point to centerline
     - Compute chainage via centerline.project(snapped_point)
     - Mark matched if distance <= max_distance_m
  6. Returns snapped coordinates with chainage

Haversine distance (for trajectory slicing):
  a = sin²(Δφ/2) + cos(φ1)·cos(φ2)·sin²(Δλ/2)
  c = 2·atan2(√a, √(1-a))
  distance = 6371000 × c

SQL for finding nearest road:
  CTE trajectory AS (SELECT ST_SetSRID(ST_GeomFromText(:trajectory_wkt), 4326) AS geom)
  SELECT g.gid FROM gh_roads g, trajectory t
  WHERE ST_DWithin(g.geom::geography, t.geom::geography, :max_distance_m)
  ORDER BY ST_Distance(g.geom::geography, t.geom::geography) ASC LIMIT 1

17. KEY FORMULAS REFERENCE
================================================================================

A. IRI CALCULATION (Simple Method)
  IRI = Σ|Δvertical_displacement| / distance_km  (m/km)
  Segment IRI = Σ|Δvert_disp| / (segment_distance_m / 1000)

B. IRI CALCULATION (ASTM QCM Quarter-Car Model)
  State: x = [sprung_disp, sprung_vel, unsprung_disp, unsprung_vel]
  dx/dt = f(x, zr):
    dx1/dt = x2
    dx2/dt = (-ks·(x1-x3) - cs·(x2-x4)) / ms
    dx3/dt = x4
    dx4/dt = (ks·(x1-x3) + cs·(x2-x4) - kt·(x3-zr)) / mu
  RK4:
    k1 = f(x, zr)
    k2 = f(x + 0.5·dt·k1, zr)
    k3 = f(x + 0.5·dt·k2, zr)
    k4 = f(x + dt·k3, zr)
    x_next = x + (dt/6)·(k1 + 2k2 + 2k3 + k4)
  IRI = Σ|x2 - x4|·dt / total_distance · 1000 (mm/m)

C. QUARTER-CAR PARAMETERS (Golden Car)
  ms = 250 kg, mu = 30 kg, ks = 63300 N/m, kt = 653000 N/m, cs = 6000 N·s/m
  v_ref = 80 km/h = 22.22 m/s
  dx = 0.025 m, fs = 100 Hz

D. PINHOLE CAMERA MODEL (Vision Dimensions)
  angle_y = atan2((y_center - cy), fy)
  z_m = camera_height_m / sin(tilt + angle_y)
  width_m = (pixel_width · z_m) / fx
  length_m = (pixel_height · z_m) / fy
  area_m2 = width_m · length_m

E. Haversine Distance (Travel Distance)
  a = sin²(Δφ/2) + cos(φ1)·cos(φ2)·sin²(Δλ/2)
  c = 2·atan2(√a, √(1-a))
  distance = 6371000 · c

F. Deduct Value (DV) Polynomial (ASTM D6433)
  DV = a × density² + b × density + c
  density = (distress_amount / section_area) × 100

G. Corrected DV (CDV) Polynomial
  CDV = a × TDV² + b × TDV + c

H. Multi-Distress Correction
  corrected_dv = total_dv × correction_factor
  correction_factor based on number of distress types (1: 1.00, 2: 0.85, 3: 0.72, 4: 0.60, 5+: 0.52)

I. PCI Calculation
  ASTM PCI = 100 - corrected_DV_sum
  Roadessy PCI = 100 - (DV_sum × 1.2)

J. SfM Depth Estimation
  P1 = K @ [I | 0], P2 = K @ [R | t]
  homog = triangulatePoints(P1, P2, pts1, pts2)
  pts3d = homog[:3] / homog[3]
  plane: n·x + d = 0, scale = camera_height / |d|/|n|
  depth_mm = |dist| · scale · 1000
  EMA: max_depth = prev × (1-α) + new × α  (α=0.35)

K. Ground Plane Intersection (Geometry Anchor)
  Ray: p = t · dir, where dir = [(u-cx)/fx, (v-cy)/fy, 1]
  Plane: n·p + d = 0
  t = -d / (n·dir)  (metric depth)
  Linear regression: metric_depth = scale × (1/inv_depth) + shift

L. MBTP Triangle Area
  X = (u - cx) · Z / fx
  Y = (v - cy) · Z / fy
  Z = depth at pixel
  area = 0.5 × |cross(p2-p1, p3-p1)|

M. MBTP Volume
  depth_deficit = max(ground_ref - depth, 0)
  pixel_area_m2 = (ground_ref / fx) × (ground_ref / fy)
  volume = Σ(depth_deficit[pothole_pixels]) × pixel_area_m2

N. Blur Detection (Laplacian Variance)
  blur_score = Var(Laplacian(gray, CV_64F))
  Threshold: < 80 → frame rejected

O. Feature Matching Quality
  Lowe's ratio: m.distance < 0.75 × n.distance

P. Confidence Score (SfM Depth)
  confidence = min(m/120, 1)×0.3 + min(inl/80, 1)×0.3 + min(d/12, 1)×0.2 + min(r/40, 1)×0.2
